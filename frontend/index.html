Ad Manager

Download Instructions

Show a custom message on every download page, just below the "Report an Issue" button. Leave blank to hide it. Example: Click the Download button 2 times to start your download.

Download Redirect URL

When set, the first click on any download button opens this URL in a new tab. The visitor must click again to download the file. Leave blank to disable.

Pop-up Ad URL

When set, the very first click anywhere on a download page opens this URL in a new tab — regardless of where the visitor clicks. After that one pop-up, the page works normally. Leave blank to disable.

Download Page — Click Ad Script

Paste a popunder / click-ad script here (like a smartlink tag). It loads on every download page and fires on the visitor's first click — the ad script handles that itself, so the popup isn't blocked. Paste JS with or without <script> tags; only the script runs, any HTML like a <button> is ignored. Works alongside the Download Redirect URL above. Leave blank to disable.

Monetag Ad Scripts

Paste Monetag script codes here. They are injected into every download page automatically. Leave blank to disable.

Sidebars are 160 px wide and only visible on screens wider than 1220 px.

File Manager

Upload Rules

DataDock is a software & games file hosting platform. All members must follow these rules when uploading or importing files. Violations will result in immediate access revocation without warning.

What You Can Upload
Software Installers & Setup Files
.exe, .msi, .dmg, .pkg, .deb, .rpm, .apk — official or cracked software setups
Games & Game Files
Full game installers, repacks, patches, updates, DLC, mods, and game-related tools
Compressed Archives of Software / Games
.zip, .rar, .7z, .tar.gz archives — as long as their contents are software or game files
Tools, Utilities & Scripts
System tools, scripts, drivers, emulators, firmware, and developer utilities
What Is Not Allowed
Images
.jpg, .png, .gif, .webp, .svg, .bmp — standalone image files are not permitted
Audio Files
.mp3, .wav, .flac, .ogg, .aac — music, podcasts, or any standalone audio
Video Files
.mp4, .mkv, .avi, .mov — movies, clips, or any standalone video content
Adult or Explicit Content
Any sexually explicit, adult, or age-restricted material is strictly forbidden
Duplicate Files
Do not re-upload a file that already exists on the platform — use the existing link instead. Check the File Manager before uploading.
Malware, Viruses & Ransomware
Never upload files intended to cause harm, steal data, or damage systems
Misleading or Disguised Files
Do not name files inaccurately. A file must be exactly what its name claims. No repackaging prohibited content inside archives.
Personal or Sensitive Data
Documents containing personal information, credentials, IDs, financial records, or private data
General Rules
Use Accurate Filenames
Name files clearly and accurately — include the version number, platform (Windows/Mac/Android), and game/software name
Search Before Uploading
Always check the File Manager for an existing copy before uploading. Duplicate files waste storage and split download counts.
Import from URL — Verified Sources Only
Only import from trusted, direct download links. Do not import from random or untrusted websites.
Keep Your API Key Private
Never share your access key with anyone. You are responsible for all activity done under your key.
Report Issues via Support
If you encounter a problem or are unsure whether a file is allowed, open a Support ticket before uploading.
Consequences of Violations

Breaking any of the above rules may result in: immediate revocation of your API key, deletion of all files uploaded under your account, and a permanent ban from the platform. There are no warnings for serious violations (adult content, malware, or deliberate misuse).
